# bd:deps-2026-09 — dependency migration + de-over-engineering rework

Condensed engagement record. Full evidence trail (17 phase reports,
review findings, UI screenshots, openapi snapshot) lived in `outputs/`
on this branch during the engagement and is archived in the cloud
workspace, not the git tree (see § Note at bottom).

## Decisions (ADRs)

- **ADR-001 r3** — REST moved under `/api/v1` with a `{data, meta}`
  response envelope (ADR-002) on all 13 route modules. **No legacy
  `/api` alias** — frontend and backend flipped together in one commit.
  **2 deliberate unversioned exceptions**: `/api/ws/prices` (WS
  protocol), `/api/health` (infra healthcheck contract). (Originally 3
  — the AI chat endpoint's unversioned prefix was the third; see AI
  removal note below.)
- **ADR-002** — `EnvelopingAPIRoute` wraps 2xx JSON bodies in
  `{data, meta}` at the ASGI response layer; `install_error_envelope`
  gives matching `{data:null, meta:{error}}` shape for 4xx/5xx on the
  same 2 path prefixes. OpenAPI schema override (cosmetic `/docs`
  accuracy) was removed in the rework — zero external API consumers.
- **ADR-005** — `uvicorn.workers.UvicornWorker` under gunicorn in prod
  (was raw uvicorn-worker equivalent); `gunicorn.conf.py` derives its
  `forwarded_allow_ips` from the same `TRUSTED_PROXIES` env var
  `core/config.py` reads, closing an ASGI-server-level proxy-header
  trust bypass (CHRIS-16/Q-10) the app-level allowlist alone couldn't see.
- **ADR-007** — `passlib[bcrypt]` removed (broken against bcrypt 5.0.0);
  replaced with direct `bcrypt.hashpw()` calls in `core/security.py`.
- **TRUSTED_PROXIES** — comma-separated IP/CIDR allowlist
  (`core/config.py`), default empty = trust nothing. Single source of
  truth for both the app-level `rate_limit.py` allowlist and
  `gunicorn.conf.py`'s ASGI-layer `forwarded_allow_ips`.

## Known follow-ups (NOT closed by this engagement — separate bd/scope)

1. **E2E — 69 pre-existing failures**, quarantined/documented, not
   fixed here (breakdown: alerts 7, auth 2, chart-timeframes 3, chart 1,
   navigation 2, portfolio 6, quote-fetch 3, screener 1, search 7,
   settings 14, sidebar 1, timeout 3, watchlist-autocomplete 5).
2. **WS auth** — `/api/ws/prices` has no server-side auth at all
   (`main.py`'s `websocket_prices`); `alert_triggered` broadcasts to
   ALL connected clients including unauthenticated ones (info
   disclosure — Sentinel SEC-3, Medium). Frontend-only gating is not a
   control. Fix = per-user WS auth + targeted delivery + connection cap.
3. **Open registration / email allowlist** — Google OAuth
   auto-provisions any `email_verified` account as a `user` role; no
   `GOOGLE_ALLOWED_EMAILS`-style allowlist exists yet (Sentinel AB-1
   residual).
4. **REQUIREMENTS.md §6 (API Endpoints) is stale/aspirational** —
   documents endpoints that don't exist (`/api/screener/run`,
   `/api/screener/presets`) and omits ~40 real ones. Needs a resync bd.
5. **TypeScript strictness ratchet** — `tsconfig.json` still
   `strict: false`; `npm run typecheck` is not in the build path
   (`npm run build` = `vite build` only). Separate bd to ratchet on.
6. **`docker-compose.dev.yml` missing `FORWARDED_ALLOW_IPS`** — dev
   runs bare `uvicorn` (no gunicorn), so `gunicorn.conf.py`'s
   `TRUSTED_PROXIES`-derived fix doesn't reach it. 1-line compose fix:
   `FORWARDED_ALLOW_IPS: ${TRUSTED_PROXIES:-}` next to the existing var
   in the backend service's `environment:` block. Logged as R1, not
   applied (compose files were out of scope for this engagement).
7. **Prod `.env` needs `TRUSTED_PROXIES` set** — for the CHRIS-16/Q-10
   fix to actually key rate-limiting by real user IP (not Caddy's) in
   prod, `TRUSTED_PROXIES` must be set to Caddy's real peer IP/CIDR in
   `/root/shotockviz/.env`, per `docs/deploy-gha.md` § Proxy trust.
   Default empty is safe (trusts nothing) but under-permissive for that
   topology until set.

## Post-engagement change — AI feature removed

User decision (2026-09, same engagement, Phase 2 scope add): the AI
chat feature (backend route, vector-search worker/service/model,
frontend panel, Caddy SSE matcher, dev-compose LLM service) was
removed entirely — its local LLM runtime was already dropped from
prod, so the code and dev-compose service were dead weight. The 3
unversioned-prefix exceptions from ADR-001 r3 are now 2:
`/api/ws/prices` and `/api/health`. The now-orphaned vector-search
table was left in place (no migration written) — drop it manually if
reclaiming space.
